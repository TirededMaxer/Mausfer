# 使用 Mausfer

## 局域网传文件

1. 在两台设备上打开 Mausfer，连接到可以互通的局域网。
2. 点击文件选择区域选择文件。桌面端也支持拖入文件。
3. 在“附近设备”中找到接收设备，点击发送。
4. 查看传输日志，确认传输完成后在接收端下载目录取文件。

设备名来自系统设置。修改系统设备名称后重新打开应用即可使用新名称。应用重启后设备 ID 会变化，不影响已接收的文件。

## 远程传文件

1. 双方在“信令服务器”填写同一个自建服务器地址，例如 `ws://你的域名:38386`，点击保存。
2. 接收方点击“开始接收”，将连接码发给发送方。
3. 发送方选择文件，输入连接码，点击“发送所选文件”。
4. 双方检查完成日志。接收方不再等待时可点击停止接收。

修改服务器设置影响下一次连接，已在进行的传输继续使用原连接。连接码有时效；失败后可重新开始接收并生成新码。

## 保存位置与后台

| 平台 | 保存位置与操作 |
| --- | --- |
| Windows / macOS | 默认系统下载目录，使用“更改下载目录”选择其他文件夹 |
| Android | 系统下载目录，可在系统文件管理器中找到；应用先验证文件，再发布到公共下载目录 |

Android 主界面返回键会返回桌面，当前连接和传输在应用进程存活期间继续。不要强行停止应用；系统省电和内存回收仍可能中断后台任务，重新打开后可以重试。

## 高级网络设置

一般保留默认公共 STUN 设置即可（Cloudflare 和 Google，无需自行部署）。直连失败且确认双方服务器地址、连接码正确时，可在“高级网络设置”配置自己可用的 TURN 服务及凭据，然后重新连接。多个 STUN/TURN 地址以逗号分隔。不需要打开 JSON 修改配置。

- 信令连接失败：检查地址的 `ws://` / `wss://`、端口、服务器进程、云安全组及防火墙。
- 能获得连接码但无法建立文件连接：检查两端网络限制，必要时配置 TURN。
- 附近设备未出现：检查是否同一可互通网络、是否启用了无线客户端隔离，以及防火墙是否拦截 UDP 43111 和 TCP 43110。
- 接收失败：检查可用磁盘空间和保存目录权限，保留未完成任务数据后重试。

服务端安装和启动见[信令服务部署说明](../signaling-server/README.md)。

传输开始后，文件选择区与传输日志之间显示收发进度；进度以接收端确认的累计字节数为准，包含断点续传的已有部分。结束、失败或停止后自动隐藏。双方更新到支持进度的新客户端后可同步显示；与旧版客户端互传时保留兼容模式。
